🔧 BACKEND - .NET 8 Web API

Models (Entidades):
- Servico (Id, Nome, Descricao, Preco, DuracaoMinutos, Categoria, ImagemUrl, Ativo)
- Produto (Id, Nome, Descricao, Preco, Stock, Categoria, ImagemUrl, Ativo)
- Profissional (Id, Nome, Especialidade, FotoUrl, Biografia, Ativo)
- Cliente (Id, Nome, Email, Telefone)
- Marcacao (Id, ClienteId, ServicoId, ProfissionalId, DataHora, Estado, Observacoes)
- Categoria (Id, Nome, Tipo) – Tipo: "Servico" ou "Produto"
- Galeria (Id, Titulo, Descricao, ImagemUrl, Categoria, DataPublicacao)
- Utilizador (Id, Nome, Email, PasswordHash, Role) – Role: "Admin" ou "Funcionario"

Funcionalidades:
- Autenticação JWT com registo/login, proteção de rotas administrativas, refresh tokens.
- Endpoints RESTful:
  - CRUD completo para Serviços, Produtos, Profissionais, Galeria.
  - Marcações: POST /api/marcacoes, GET /api/marcacoes, GET /api/marcacoes/disponibilidade?data=&profissionalId=, PUT /api/marcacoes/{id}/estado.
  - GET /api/dashboard – estatísticas.
- Validações: conflitos de horário, Data Annotations em português, middleware global de exceções (mensagens em português).
- Base de Dados: Entity Framework Core com SQL Server, migrations automáticas, seeders com dados de exemplo (mínimo 5 serviços, 10 produtos, 3 profissionais) – textos em português de Portugal.
- Serviços adicionais: envio de email de confirmação (mock, em português, a mencionar IzaBraids), upload de imagens (sistema de ficheiros local ou Azure Blob).
- Swagger documentado em português, CORS para localhost:3000 e localhost:5173, Serilog, configuração em appsettings.json e appsettings.Development.json.

🎨 FRONTEND – React 18+ com Vite (JavaScript)

Interface totalmente em português de Portugal. Nome IzaBraids em todo o lado.

Páginas Públicas:
1. Home – banner, serviços destacados, testemunhos, CTA.
2. Serviços – lista com filtros por categoria, preços (€), duração.
3. Produtos – catálogo, filtros, pesquisa, carrinho.
4. Marcação – passo a passo: serviço → profissional → data/hora → dados cliente → confirmação.
5. Galeria – grid com lightbox, filtros, lazy loading.
6. Contactos – info, mapa, formulário.

Área Administrativa (protegida por login):
7. Login
8. Dashboard – cards, gráficos, próximas marcações.
9. Gestão de Marcações – tabela, confirmar/cancelar.
10. Gestão de Serviços – CRUD modal + upload imagem.
11. Gestão de Produtos – CRUD modal + upload imagem, gestão de stock.
12. Gestão de Profissionais – CRUD modal + upload foto.
13. Gestão de Galeria – upload múltiplo, organizar, eliminar.

Componentes Reutilizáveis:
- Navbar (com IzaBraids), Footer, Cards, Modal, Botão (variantes, texto PT), Input (validação PT), Spinner, Toast (PT), Calendário (pt-PT), Tabela paginada, Breadcrumbs, ProtectedRoute.

Tecnologias e Bibliotecas:
- React 18 + Vite (JavaScript)
- React Router v6, Tailwind CSS, TanStack Query, React Hook Form + Zod (mensagens PT), Axios, Context API, React Hot Toast, React DatePicker (pt-PT), React Icons, React Lightbox, Recharts, Framer Motion (opcional), React Helmet Async.

Funcionalidades Adicionais:
- Carrinho persistido em localStorage
- Responsivo mobile-first
- Animações suaves
- Página 404 em português
- Lazy loading de imagens
- SEO com React Helmet Async (títulos/meta em PT, incluir IzaBraids)
